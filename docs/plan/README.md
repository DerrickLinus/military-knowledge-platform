**一期（MVP）功能**：智能问答（含教学模式增强）· 文档研读 · 自动综述 · 思维导图 · 扫描件支持（OCR）

**关键决策速览**：私有云 + dmxapi 网关（仅开源模型，基座 `qwen3.8-27b`）；部门=租户的零侵入权限映射（多级部门/文档级权限/密级走演进路线）；MVP 不建 gateway、不做统一认证，应用二/三以 API 契约预留；二开全部走 WeKnora 官方扩展点、跟住上游。

**评审需输出**（见技术方案 §11）：OCR 方案甲/乙（扫描件是否允许出网）、POC 用例集确认。（已确认：Rerank 统一采用 dmxapi 的 `qwen3-rerank`；允许按任务路由大模型。）
